Origin is a desktop program, so a web page cannot open it or exchange data with it live. These three routes move your work into Origin.

  1. Clipboard. Copy the table and paste it into an Origin worksheet. Without headers the values land in the data rows directly.
  2. Script. The script below rebuilds this worksheet in Origin with names, units and X/Y designations, and draws the current plot as a native, editable Origin graph. Paste it into Origin's Python console, or run it from Python on a Windows PC with Origin installed. It follows the documented originpro API and has not been run against your Origin version.
  3. File. Save the table as CSV and drag it into Origin, or use Data, Import From File.
